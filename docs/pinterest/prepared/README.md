# Prepared Pinterest pins

Prepared 26 October 2026 (Asia/Karachi). **64 pins, IDs 012–075, are saved locally and awaiting owner review. None was published, scheduled or uploaded in this batch.** The existing 11 published pins remain in the posting log.

Open [the visual index](index.html) to browse and filter. [queue.csv](queue.csv) contains all posting copy; [manifest.json](manifest.json) contains complete structured metadata. [matrix.json](matrix.json) maps the full 75 keyword/location combinations and 15 source families. [validation.json](validation.json) records file, dimensions, unique-image, original-copy integrity and copy checks. [gallery-check.json](gallery-check.json) records the gallery's desktop/mobile and interaction checks.

Each individual folder contains:

- `pin-NNN.png`: original 1024×1536 generated artwork, unchanged after generation.
- `posting.md`: ready-to-copy title, description with three hashtags, destination, alt text and posting details.
- `metadata.json`: exact fields, source path, actual dimensions, hash, status and blank publication/performance fields.
- `prompt.txt`: full prompt actually sent to built-in image generation.
- `review.json`: visual check, generation source and known source differences.

All 64 designs used the built-in image generation tool, one call per asset. Fine color, crop and detail differences are recorded; these are generated designs based on real photos. Five treatments across 15 source photos complete the 75-creative plan, including the 11 existing images.
